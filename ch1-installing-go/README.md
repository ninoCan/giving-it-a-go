# Setting up a developer environment

> A good start is half the finish.

## Guidelines

I'll be following the [first chapter](https://quii.gitbook.io/learn-go-with-tests/go-fundamentals/install-go), and additionally take note
of the vim/neovim plugins needed to get Going.

### In brief

- Skim through first chapter
- Use webi to install:
    0. [go](https://github.com/webinstall/webi-installers/tree/main/golang), but later revert to native installation
    0. [vim-go](https://github.com/webinstall/webi-installers/tree/main/vim-go),
    0. [go-essentials](https://github.com/webinstall/webi-installers/tree/main/go-essentials)
    0. [vim-essentials](https://github.com/webinstall/webi-installers/tree/main/vim-essentials)
- learn to read through Golang's CLI help with `go help <topic>`
- install `golangci-lint` natively
